# Quotes Scraper — лабораторная работа 3

Скрапер на Ubuntu 24.04 (Multipass VM): cloud-init — только bootstrap,
вся настройка — Ansible. Redis Streams принимает задания, скрапер пишет
JSON на диск, Nginx отдаёт результаты по HTTP.

README дополняется: требования к host, архитектура и команды `make`.
